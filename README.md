# Run and deploy your AI Studio app 1

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/e87c1c18-9736-4c44-b56e-7968bdf4418c

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run this command
   'npm.cmd install'
3. Run the app:
   `npm.cmd run dev`
